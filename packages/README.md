# packages

桌面程序依赖的共享库：

- `app-lib`：后端核心库（Rust），负责账户、下载、安装、导入、校验与游戏启动。
- `ui`、`assets`：共享 Vue 组件库与图标、样式资源。
- `api-client`、`utils`、`blog`、`tooling-config`：前端 API 客户端、工具函数、更新日志类型与代码规范配置。
- `ariadne`、`async-minecraft-ping`、`daedalus`、`modrinth-content-management`、`path-util`、`serde-binhum`：后端使用的 Rust 辅助库。
